# Computer Lab Helpdesk & Asset Management System

Full-stack starter project with frontend, Flask REST backend, SQLite database, JWT authentication, ML ticket-priority prediction, sample data, API documentation and setup files.

## Run
1. python -m venv venv
2. Windows: venv\Scripts\activate
3. pip install -r requirements.txt
4. copy .env.example .env
5. python ml_model/train_model.py
6. python backend/app.py
7. Open http://127.0.0.1:5000
